## Detalles por Plataforma

### 1. Tidal
- **URL**: https://tidal.com
- **API**: ✅ Developer Portal (https://developer.tidal.com/)
- **Pago por stream**: ~$0.012-0.013 (mayor que Spotify)
- **Modelo**: HiFi y HiRes audio, enfoque en calidad
- **Playlist**: Sí, incluye curación editorial
- **Usuarios**: ~5 millones
- **Ventajas**: Mayor pago a artistas, audio de alta fidelidad, respaldado por artistas (Jay-Z)
- **Limitaciones API**: Registro requerido, documentación limitada, cuotas de uso

### 2. Deezer
- **URL**: https://deezer.com
- **API**: ✅ API REST (https://developers.deezer.com/api)
- **Pago por stream**: ~$0.004-0.006 (similar o mejor que Spotify)
- **Modelo**: HiFi streaming, "User-centric payment system" (UCPS)
- **Playlist**: Sí, incluye mixes y curación
- **Usuarios**: ~10 millones (fuerte en Francia, Brasil)
- **Ventajas**: Modelo UCPS más justo, HiFi incluido, API completa
- **Limitaciones API**: Términos de uso estrictos, requiere registro

### 3. Bandcamp
- **URL**: https://bandcamp.com
- **API**: ❌ No hay API pública oficial
- **Pago al artista**: 80-85% de ventas directas al artista
- **Modelo**: Venta directa (descargas, vinilo, merchandise)
- **Playlist**: No tiene sistema de playlists tradicional
- **Usuarios**: ~10 millones de compradores
- **Ventajas**: El más ético para artistas, venta directa, sin intermediarios
- **Limitaciones**: Sin streaming ilimitado, sin API para migración, modelo de compra

### 4. SoundCloud
- **URL**: https://soundcloud.com
- **API**: ✅ API OAuth 2.1 (https://developers.soundcloud.com/)
- **Pago por stream**: ~$0.003-0.004 (similar a Spotify en plan Go)
- **Modelo**: "Fan-powered royalties" (pago proporcional a escucha)
- **Playlist**: Sí, incluye mixes y colecciones
- **Usuarios**: ~300 millones (muchos son creadores)
- **Ventajas**: API completa, modelo fan-powered, plataforma para artistas emergentes
- **Limitaciones**: Calidad de audio estándar, API con límites estrictos

### 5. Apple Music
- **URL**: https://music.apple.com
- **API**: ✅ MusicKit (https://developer.apple.com/musickit/)
- **Pago por stream**: ~$0.007-0.01 (mayor que Spotify)
- **Modelo**: Suscripción familiar, sin tier gratuito
- **Playlist**: Sí, curación editorial fuerte
- **Usuarios**: ~100 millones
- **Ventajas**: Mayor pago a artistas, sin anuncios, integración ecosistema Apple
- **Limitaciones API**: Solo para desarrolladores Apple, requiere cuenta de desarrollador

### 6. YouTube Music
- **URL**: https://music.youtube.com
- **API**: ⚠️ YouTube Data API v3 (general, no específica para música)
- **Pago por stream**: ~$0.002-0.004 (variable)
- **Modelo**: Freemium con anuncios, YouTube Premium incluido
- **Playlist**: Sí, mixes inteligentes
- **Usuarios**: ~100+ millones (parte de YouTube)
- **Ventajas**: Catálogo masivo, integrates con YouTube, disponibilidad global
- **Limitaciones API**: API general, no optimizada para música, monetización variable

### 7. Qobuz
- **URL**: https://qobuz.com
- **API**: ⚠️ Limitada a partners
- **Pago por stream**: ~$0.013-0.015 (mayor que Spotify)
- **Modelo**: HiRes audio, venta de descargas
- **Playlist**: Sí, curación editorial
- **Usuarios**: ~1 millón
- **Ventajas**: El mayor pago por stream, calidad audio extrema (24-bit)
- **Limitaciones**: API muy restringida, usuarios limitados, enfoque europeo

### 8. Amazon Music
- **URL**: https://music.amazon.com
- **API**: ❌ No hay API pública
- **Pago por stream**: ~$0.004
- **Modelo**: Integrado con Prime, tier Unlimited
- **Playlist**: Sí, X-Ray lyrics
- **Usuarios**: ~55 millones
- **Ventajas**: Integración con ecosistema Alexa/Prime
- **Limitaciones**: Sin API pública, pago bajo

### 9. Anghami
- **URL**: https://anghami.com
- **API**: ❌ No hay API pública
- **Pago por stream**: ~$0.002-0.003
- **Modelo**: Freemium, fuerte en Medio Oriente
- **Playlist**: Sí, mixes y curación regional
- **Usuarios**: ~100+ millones (registrados)
- **Ventajas**: Líder en mercado árabe, contenido regional exclusivo
- **Limitaciones**: Sin API, foco regional limitado

### 10. Napster
- **URL**: https://napster.com
- **API**: ✅ API disponible
- **Pago por stream**: ~$0.019-0.021 (el más alto)
- **Modelo**: Suscripción completa, sin tier gratuito
- **Playlist**: Sí
- **Usuarios**: ~3 millones
- **Ventajas**: El mayor pago por stream de la industria
- **Limitaciones**: Base de usuarios muy pequeña, poco conocido

## Ranking por Ética y Pago a Artistas

### Top 5 (Mejor pago + prácticas éticas):
1. **Bandcamp** - 80-85% al artista (venta directa)
2. **Napster** - ~$0.021/stream
3. **Qobuz** - ~$0.015/stream + HiRes
4. **Tidal** - ~$0.013/stream + HiFi
5. **Apple Music** - ~$0.01/stream

### Top 5 (Mejor API para migración):
1. **Spotify** - API completa y documentada
2. **SoundCloud** - API OAuth 2.1 moderna
3. **Deezer** - API REST completa
4. **Tidal** - Developer Portal disponible
5. **Apple Music** - MusicKit (limitado a Apple)

## Recomendación para Migración de Playlists

**Mejor opción**: **Deezer** o **Tidal**
- Ambos tienen APIs públicas
- Mejor pago que Spotify
- Disponibles internacionalmente
- Soportan playlists

**Alternativa ética**: **Bandcamp**
- El más justo para artistas
- Pero sin modelo de streaming/ilimitado
- Sin API para migración automática

**Para desarrolladores**: **SoundCloud**
- API moderna (OAuth 2.1)
- Modelo fan-powered justo
- Buen catálogo de artistas independientes

## Notas Técnicas

### APIs Más Accesibles:
1. **Deezer**: REST API con documentación completa
2. **SoundCloud**: OAuth 2.1 con PKCE, buena documentación
3. **Tidal**: Developer Portal con registro
4. **Spotify**: La más madura pero peor pago

### Para Integración/Migración:
- Usar APIs de ambas plataformas (origen y destino)
- Implementar matching por ISRC (International Standard Recording Code)
- Respetar límites de rate limiting
- Obtener permisos del usuario para acceder a sus playlists
